Curso Angular + TypeScript

Autodidacta, interactivo y visual

1. Introducción

Angular es un framework para construir aplicaciones web SPA.

TypeScript es un superconjunto de JavaScript que permite tipado fuerte.

2. Instalación

npm install -g @angular/cli
ng new mi-proyecto
cd mi-proyecto
ng serve

3. Primer componente

ng generate component saludo
<h1>¡Hola desde Angular!</h1>
