Módulo 1: Fundamentos de TypeScript

¿Qué es TypeScript?

Es un superconjunto de JavaScript que añade tipos, interfaces, clases y más.

let nombre: string = 'Juan';
let edad: number = 25;

Tipos primitivos

  • string, number, boolean, any
let activo: boolean = true;
let lista: number[] = [1, 2, 3];

Interfaces y Clases

interface Persona {
  nombre: string;
  edad: number;
}

class Empleado implements Persona {
  constructor(public nombre: string, public edad: number) {}
}

Módulo 2: Introducción a Angular

¿Qué es Angular?

Framework de desarrollo frontend basado en componentes, desarrollado por Google.

ng new mi-app
ng serve

Componentes

@Component({
  selector: 'app-root',
  templateUrl: './app.component.html'
})
export class AppComponent {
  titulo = 'Mi app Angular';
}

Extras: Pipes Personalizados

@Pipe({ name: 'mayusculas' })
export class MayusculasPipe implements PipeTransform {
  transform(valor: string): string {
    return valor.toUpperCase();
  }
}

Extras: Guards de rutas

canActivate(route: ActivatedRouteSnapshot): boolean {
  return this.authService.isLoggedIn();
}
